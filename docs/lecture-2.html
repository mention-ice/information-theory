Summary

  • The type \(\hat{\P}_{x^n}\) of a sequence is its empirical distribution. There are only \(K_{n,M} \le (n+1)^{M-1}\) types, polynomially many, for \(M^n\) sequences.
  • All sequences of a type class have the same probability under an i.i.d. source: \(\Q^n(x^n) = 2^{-nH(\hat{\P}\|\Q)}\) for \(x^n\in\Tcal^{(n)}(\hat{\P})\). The most likely source for \(x^n\) is its type.
  • A type class has \(|\Tcal^{(n)}(\hat{\P})| = \gamma_n(\hat{\P})\,2^{nH(\hat{\P})}\) sequences and probability \(\Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) = \gamma_n(\hat{\P})\,2^{-nD(\hat{\P}\|\Q)}\), where \(\gamma_n(\hat{\P})\in\bigl[K_{n,M}^{-1},1\bigr]\) is polynomial in \(n\). On the exponential scale, the size is \(2^{nH}\) and the probability is \(2^{-nD}\).
  • The typical set \(\Tcal_\epsilon^{(n)}(\P)\) is the union of the type classes close to \(\P\). It has probability at least \(1-\delta_T(\epsilon,n,\P)\to 1\) and about \(2^{nH(\P)}\) sequences, each of probability about \(2^{-nH(\P)}\) (AEP).
  • An \(\rv{X}^n\sim\P_{\rv{X}}^n\) drawn independently of a typical \(y^n\) is jointly typical with it with probability about \(2^{-nI(\rv{X};\rv{Y})}\).

2.1 Types, type classes

Let \(\Xcal = \{a_1,\ldots,a_M\}\) be a finite alphabet, \(M = |\Xcal|\). The type of a sequence \(x^n\in\Xcal^n\) is its empirical distribution:

\[\begin{aligned} \hat{\P}_{x^n}(a) &:= \frac{1}{n}\sum_{i=1}^n \ind{x_i = a}, \qquad a\in\Xcal, \\ \hat{\P}_{x^n} &:= \bigl[\,\hat{\P}_{x^n}(a) :\ a\in\Xcal\,\bigr]. \end{aligned}\]

A type is thus of the form \(\hat{\P} = \frac{1}{n}\,[n_1,\ldots,n_M]\), where \(n_i\) is the number of occurrences of \(a_i\) in the sequence.

The set of types is

\[\begin{aligned} \Pcal_n \equiv \Pcal_n(\Xcal) &:= \bigl\{\hat{\P}_{x^n} :\ x^n\in\Xcal^n\bigr\} \\ &= \Bigl\{\frac{1}{n}\,[n_1,\ldots,n_M] :\ n_i\in\mathbb{Z}_+,\ \sum_{i=1}^M n_i = n\Bigr\} \\ &\subset \Pcal(\Xcal) := \Bigl\{[p_1,\ldots,p_M] :\ p_i \ge 0,\ \sum_{i=1}^M p_i = 1\Bigr\}, \end{aligned}\]

where the set of distributions \(\Pcal(\Xcal)\) is the \((M-1)\)-simplex.

The type class of a type \(\hat{\P}\in\Pcal_n\) is

\[\Tcal^{(n)}(\hat{\P}) := \bigl\{x^n\in\Xcal^n :\ \hat{\P}_{x^n} = \hat{\P}\bigr\}.\]

Example. Let \(\Xcal = \{0,1\}\) (so \(a_1 = 0\), \(a_2 = 1\), \(M = 2\)) and \(n = 4\). The sequence \(x^4 = 0110\) contains \(n_1 = 2\) zeros and \(n_2 = 2\) ones, so its type is

\[\hat{\P}_{0110} = \frac{1}{4}\,[2,2] = \Bigl[\frac{1}{2},\frac{1}{2}\Bigr].\]

The set of types has \(n+1 = 5\) elements,

\[\Pcal_4 = \Bigl\{[0,1],\ \Bigl[\frac{1}{4},\frac{3}{4}\Bigr],\ \Bigl[\frac{1}{2},\frac{1}{2}\Bigr],\ \Bigl[\frac{3}{4},\frac{1}{4}\Bigr],\ [1,0]\Bigr\},\]

equally spaced points on the segment \(\Pcal(\Xcal) = \bigl\{[p,1-p] :\ p\in[0,1]\bigr\}\), which is the \(1\)-simplex. The type class of \(\bigl[\frac{1}{2},\frac{1}{2}\bigr]\) consists of the \(\binom{4}{2} = 6\) sequences with two zeros and two ones:

\[\Tcal^{(4)}\Bigl(\Bigl[\frac{1}{2},\frac{1}{2}\Bigr]\Bigr) = \{0011,\ 0101,\ 0110,\ 1001,\ 1010,\ 1100\}.\]

The five type classes, of sizes \(1, 4, 6, 4, 1\), partition the \(2^4 = 16\) sequences of \(\Xcal^4\).

In this lecture, we answer three questions:

  • the number of types,
  • the size of each type class,
  • the probability of each type class.

2.2 Size and probability of type classes

2.2.1 Number of type classes

By “stars and bars” (Problem 2 of the exercises),

\[\begin{aligned} K_{n,M} := |\Pcal_n| = \binom{n+M-1}{M-1} &\le (n+1)^{M-1} \\ &\le n^M \qquad \text{if } n\ge M \text{ and } n\ge 3. \end{aligned}\]
Proof.

For the last bound, \((n+1)^{M-1} = n^{M-1}\bigl(1+\frac1n\bigr)^{M-1} \le n^{M-1}\bigl(1+\frac1n\bigr)^n < e\,n^{M-1} \le n^M\) when \(M-1\le n\) and \(n\ge 3\).

2.2.2 Size of each type class

For a type \(\hat{\P}\in\Pcal_n\) (Problem 3 of the exercises),

\[\begin{aligned} |\Tcal^{(n)}(\hat{\P})| &= \binom{n}{n_1,\ldots,n_M} = \binom{n}{n\hat{\P}(a_1),\ldots,n\hat{\P}(a_M)} \\ &= \frac{n!}{\prod_{a\in\Xcal}\bigl(n\hat{\P}(a)\bigr)!}. \end{aligned}\]

For \(M = 2\), a type is \(\hat{\P} = \frac{1}{n}[k, n-k]\) with \(k\in\{0,\ldots,n\}\), and we get the binomial coefficient

\[|\Tcal^{(n)}(\hat{\P})| = \binom{n}{k} = \frac{n!}{k!\,(n-k)!},\]

the number of binary sequences of length \(n\) with \(k\) occurrences of \(a_1\). For example, \(\binom{4}{2} = 6\) in the example of Section 2.1.

The type classes partition \(\Xcal^n\), as sketched below. Counting the sequences class by class therefore gives

\[\sum_{\hat{\P}\in\Pcal_n} |\Tcal^{(n)}(\hat{\P})| = \sum_{\substack{n_1,\ldots,n_M\in\mathbb{Z}_+\\ n_1+\cdots+n_M = n}} \binom{n}{n_1,\ldots,n_M} = M^n,\]

which is the multinomial theorem for \((1+\cdots+1)^n\). For \(M = 2\), it reads \(\sum_{k=0}^n \binom{n}{k} = 2^n\), e.g., \(1+4+6+4+1 = 16\) for \(n = 4\).

Stirling’s approximation.

For every integer \(n\ge 1\) (Robbins’ form, which we use without proof),

\[n! = \sqrt{2\pi n}\,\Bigl(\frac{n}{e}\Bigr)^n e^{\frac{1}{12n+\theta_n}}, \qquad \theta_n\in[0,1].\]

Applied to each factorial, it gives, for \(\hat{\P}\in\Pcal_n\) with \(n_i = n\hat{\P}(a_i) \ge 1\) for all \(i\),

\[|\Tcal^{(n)}(\hat{\P})| = 2^{nH(\hat{\P})}\, \sqrt{\frac{n}{n_1\cdots n_M}\,(2\pi)^{-(M-1)}}\; e^{\frac{1}{12n+\theta_n} - \sum_{i=1}^{M}\frac{1}{12n_i+\theta_{n_i}}}.\]

Indeed, since \(n = \sum_i n_i\), the factors \(e^{-n}\) and \(\prod_i e^{-n_i}\) cancel, and \(n^n/\prod_i n_i^{n_i} = 2^{nH(\hat{\P})}\) since \(n_i/n = \hat{\P}(a_i)\). The factor after \(2^{nH(\hat{\P})}\) is polynomial in \(n\); we come back to it in Section 2.2.3. If \(n_i = 0\) for some \(i\), we simply remove \(a_i\) from the alphabet: the formula above holds with \(M\) replaced by \(\tilde{M} := |\{a\in\Xcal :\ \hat{\P}(a) > 0\}|\), the effective size of the alphabet for the type \(\hat{\P}\).

2.2.3 Probability of type classes

Let \(\Q\in\Pcal(\Xcal)\) be a probability measure with pmf \(q\), and let \(\Q^n\) be the i.i.d. distribution on \(\Xcal^n\), that is, the product measure with pmf \(q^n(x^n) := \prod_{i=1}^n q(x_i)\). Since the alphabet is finite, a measure is determined by its pmf, and we use the same letter for both: \(\Q(a) := \Q(\{a\}) = q(a)\), \(\Q^n(x^n) := \Q^n(\{x^n\}) = q^n(x^n)\), and \(\Q^n(\mathcal{A}) = \sum_{x^n\in\mathcal{A}} \Q^n(x^n)\) for every \(\mathcal{A}\subseteq\Xcal^n\). The same shorthand is used for \(\P\) and for types.

  • Probability of a sequence under \(\Q^n\).

    \[\begin{aligned} \Q^n(x^n) &= \prod_{i=1}^n \Q(x_i) = \prod_{a\in\Xcal}\Q(a)^{n\hat{\P}(a)} \\ &= 2^{n\sum_{a\in\Xcal}\hat{\P}(a)\log\Q(a)} \\ &= 2^{-nH(\hat{\P}\|\Q)}, \end{aligned}\]

    where \(\hat{\P} := \hat{\P}_{x^n}\) is the type of \(x^n\). Since \(H(\hat{\P}\|\Q) = H(\hat{\P}) + D(\hat{\P}\|\Q)\), with \(D(\hat{\P}\|\Q) = 0\) if and only if \(\Q = \hat{\P}\), the maximum-likelihood estimate of the source from \(x^n\) is its type:

    \[\Q^* := \operatorname*{arg\,max}_{\Q\in\Pcal(\Xcal)} \Q^n(x^n) = \hat{\P}_{x^n}.\]

  • Probability of a type class. For every \(\hat{\P}\in\Pcal_n\),

    \[\begin{aligned} \Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) &= \sum_{x^n\in\Tcal^{(n)}(\hat{\P})} \Q^n(x^n) \\ &= |\Tcal^{(n)}(\hat{\P})|\, 2^{-nH(\hat{\P}\|\Q)}. \qquad\qquad \circnum{\star} \end{aligned}\]

  • Most likely source for a type class. For every \(\hat{\P}\in\Pcal_n\) and every \(\Q\in\Pcal(\Xcal)\),

    \[\hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) \ge \Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr),\]

    from \(\circnum{\star}\), since \(H(\hat{\P}\|\Q) \ge H(\hat{\P})\).

  • Most likely type class under a source. For every \(\hat{\P},\hat{\Q}\in\Pcal_n\),

    \[\hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) \ge \hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\Q})\bigr),\]

    that is, the type class of \(\hat{\P}\) is the most likely one under \(\hat{\P}^n\). Indeed, using \(s!/t! \ge t^{s-t}\) with \(s = n\hat{\Q}(a)\) and \(t = n\hat{\P}(a)\), we have

    \[\begin{aligned} \frac{|\Tcal^{(n)}(\hat{\P})|}{|\Tcal^{(n)}(\hat{\Q})|} = \prod_{a\in\Xcal}\frac{(n\hat{\Q}(a))!}{(n\hat{\P}(a))!} &\ge \prod_{a\in\Xcal}\bigl(n\hat{\P}(a)\bigr)^{n(\hat{\Q}(a)-\hat{\P}(a))} = 2^{n(H(\hat{\P}) - H(\hat{\Q}\|\hat{\P}))}, \end{aligned}\]

    so, by \(\circnum{\star}\),

    \[\begin{aligned} \frac{\hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr)}{\hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\Q})\bigr)} &= \frac{|\Tcal^{(n)}(\hat{\P})|}{|\Tcal^{(n)}(\hat{\Q})|}\, \frac{2^{-nH(\hat{\P}\|\hat{\P})}}{2^{-nH(\hat{\Q}\|\hat{\P})}} \\ &\ge 2^{n(H(\hat{\P})-H(\hat{\Q}\|\hat{\P})) - n(H(\hat{\P}) - H(\hat{\Q}\|\hat{\P}))} \\ &= 1. \end{aligned}\]

    If the uniform distribution \(\hat{\P}\) is a type (\(M\) divides \(n\)), then \(H(\hat{\Q}\|\hat{\P}) = \log M = H(\hat{\P})\) for every \(\hat{\Q}\), so the size bound above has exponent \(0\): the uniform type class is the largest.

  • Maximum-likelihood probability of a type class. For \(\hat{\P}\in\Pcal_n\), it is defined as

    \[\gamma_n(\hat{\P}) := \hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) = \max_{\Q\in\Pcal(\Xcal)} \Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr),\]

    since the maximum is attained at \(\Q = \hat{\P}\), as shown above. By \(\circnum{\star}\) with \(\Q = \hat{\P}\),

    \[|\Tcal^{(n)}(\hat{\P})| = 2^{nH(\hat{\P})}\, \gamma_n(\hat{\P}).\]

    Since the \(K_{n,M}\) type classes partition \(\Xcal^n\) and \(\Tcal^{(n)}(\hat{\P})\) is the most likely one under \(\hat{\P}^n\), we have \(1 \ge \gamma_n(\hat{\P}) \ge K_{n,M}^{-1}\). Hence, with \(\eta_n := \frac{1}{n}\log \gamma_n(\hat{\P})\),

    \[|\Tcal^{(n)}(\hat{\P})| = 2^{n(H(\hat{\P})+\eta_n)}, \qquad -\frac{\log K_{n,M}}{n} \le \eta_n \le 0,\]

    so that \(\eta_n\to 0\) as \(n\to\infty\), uniformly over \(\hat{\P}\in\Pcal_n\). Moreover, Stirling’s approximation in Section 2.2.2 gives (Problem 4 of the exercises)

    \[\gamma_n(\hat{\P}) \simeq (2\pi n)^{-\frac{\tilde{M}-1}{2}}\, \tilde{M}^{\frac{\tilde{M}}{2}}\, 2^{\frac{\tilde{M}}{2} D(\mathrm{U}\|\hat{\P})},\]

    where \(\mathrm{U}\) is the uniform distribution on \(\mathrm{supp}(\hat{\P})\), \(\tilde{M}\) is the effective alphabet size defined in Section 2.2.2, and \(\simeq\) means that the ratio of both sides tends to \(1\) as \(n\to\infty\). So \(\gamma_n(\hat{\P})\) is polynomial in \(n\), and goes to \(0\) polynomially fast if \(\tilde{M} \ge 2\)! Among types with the same support size \(\tilde{M}\), the uniform type has the smallest maximum-likelihood probability, although its type class is the largest.

  • For \(\hat{\P}\in\Pcal_n\) and \(\Q\in\Pcal(\Xcal)\),

    \[\begin{aligned} \Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) &= |\Tcal^{(n)}(\hat{\P})|\, 2^{-nH(\hat{\P}\|\Q)} \\ &= \gamma_n(\hat{\P})\, 2^{nH(\hat{\P})-nH(\hat{\P}\|\Q)} \\ &= \gamma_n(\hat{\P})\, 2^{-nD(\hat{\P}\|\Q)}. \end{aligned}\]

    If \(\hat{\P}\ne\Q\), then \(D(\hat{\P}\|\Q) > 0\), and the type class of \(\hat{\P}\) has an exponentially low probability under \(\Q^n\).

Summary. For \(\hat{\P}\in\Pcal_n\), \(x^n\in\Tcal^{(n)}(\hat{\P})\), and \(\Q\in\Pcal(\Xcal)\),

\[\begin{aligned} |\Pcal_n| &= K_{n,M} \le (n+1)^{M-1}, & \Q^n(x^n) &= 2^{-nH(\hat{\P}\|\Q)}, \\ |\Tcal^{(n)}(\hat{\P})| &= \gamma_n(\hat{\P})\, 2^{nH(\hat{\P})}, & \Q^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) &= \gamma_n(\hat{\P})\, 2^{-nD(\hat{\P}\|\Q)}, \end{aligned}\]

where \(\gamma_n(\hat{\P}) := \hat{\P}^n\bigl(\Tcal^{(n)}(\hat{\P})\bigr) \in \bigl[K_{n,M}^{-1}, 1\bigr]\).

2.3 Typical sequences

Let \(\P\in\Pcal(\Xcal)\) and \(\epsilon\in[0,1]\). A sequence \(x^n\in\Xcal^n\) is called \(\epsilon\)-typical with respect to \(\P\), denoted by \(x^n\in\Tcal_\epsilon^{(n)}(\P)\), if its type is close to \(\P\):

\[|\hat{\P}_{x^n}(a) - \P(a)| \le \epsilon\,\P(a),\quad\text{i.e.,}\quad (1-\epsilon)\P(a) \le \hat{\P}_{x^n}(a) \le (1+\epsilon)\P(a), \qquad \forall\,a\in\Xcal.\]

Therefore, we call

\[\begin{aligned} \Tcal_\epsilon^{(n)}(\P) &:= \bigl\{x^n :\ |\hat{\P}_{x^n}(a) - \P(a)| \le \epsilon\,\P(a),\ \forall\,a\in\Xcal\bigr\} \\ &= \bigcup\bigl\{\Tcal^{(n)}(\hat{\P}) :\ \hat{\P}\in\Pcal_n,\ |\hat{\P}(a) - \P(a)| \le \epsilon\,\P(a),\ \forall\,a\in\Xcal\bigr\} \end{aligned}\]

the strongly typical set, or set of \(\epsilon\)-typical \(n\)-sequences; it is a union of type classes. If \(\P(a) = 0\), the constraint forces \(\hat{\P}_{x^n}(a) = 0\), so the type of a typical sequence is absolutely continuous with respect to \(\P\): \(\hat{\P}_{x^n}\ll\P\) for every \(x^n\in\Tcal_\epsilon^{(n)}(\P)\). If \(\epsilon < 1\), then \(\hat{\P}_{x^n}(a) \ge (1-\epsilon)\P(a) > 0\) whenever \(\P(a) > 0\), so the two even have the same support. For \(\epsilon = 0\), the typical set is \(\Tcal^{(n)}(\P)\) if \(\P\) is a type, and \(\emptyset\) otherwise. Typicality can also be written as

\[\Bigl|\frac{\hat{\P}_{x^n}(a)}{\P(a)} - 1\Bigr| \le \epsilon, \qquad \forall\,a\in\Xcal,\]

with the conventions \(c/0 = \infty\) for \(c > 0\) and \(0/0 = 1\).

Typical average lemma. For every function \(g:\Xcal\to\mathbb{R}\) and every \(x^n\in\Tcal_\epsilon^{(n)}(\P)\),

\[\Bigl|\frac{1}{n}\sum_{i=1}^n g(x_i) - \EE_\P\bigl[g(\rv{X})\bigr]\Bigr| \le \epsilon\,\EE_\P\bigl[|g(\rv{X})|\bigr].\]
Proof.

The average is \(\EE_{\hat{\P}_{x^n}}[g(\rv{X})]\), and \(|\hat{\P}_{x^n}(a)/\P(a) - 1| \le \epsilon\) for all \(a\). Since \(\hat{\P}_{x^n}\ll\P\), the ratio \(\hat{\P}_{x^n}(a)/\P(a)\) is the Radon–Nikodym derivative \(\frac{\mathrm{d}\hat{\P}_{x^n}}{\mathrm{d}\P}(a)\), and by a change of measure,

\[\Bigl|\EE_{\hat{\P}_{x^n}}\bigl[g(\rv{X})\bigr] - \EE_\P\bigl[g(\rv{X})\bigr]\Bigr| = \Bigl|\EE_\P\Bigl[\Bigl(\frac{\hat{\P}_{x^n}(\rv{X})}{\P(\rv{X})} - 1\Bigr) g(\rv{X})\Bigr]\Bigr| \le \epsilon\,\EE_\P\bigl[|g(\rv{X})|\bigr]. \qedhere\]

Properties. Let \(M^* := |\{a\in\Xcal :\ \P(a)>0\}|\), \(c_\P := \min_{a:\,\P(a)>0} \P(a)^2\), and \(\rv{X}^n\sim\P^n\).

  1. Probability of a sequence. For every \(x^n\in\Tcal_\epsilon^{(n)}(\P)\),

    \[2^{-n(1+\epsilon)H(\P)} \le \P^n(x^n) \le 2^{-n(1-\epsilon)H(\P)},\]

    \(D(\hat{\P}_{x^n}\|\P) \le \log(1+\epsilon)\), and \(|H(\hat{\P}_{x^n}) - H(\P)| \le \epsilon H(\P) + \log(1+\epsilon)\).

  2. Probability of the set.

    \[\P^n\bigl(\rv{X}^n\notin\Tcal_\epsilon^{(n)}(\P)\bigr) \le \delta_T(\epsilon,n,\P) := 2M^* e^{-2n\epsilon^2 c_\P},\]

    so \(\P^n\bigl(\Tcal_\epsilon^{(n)}(\P)\bigr) \to 1\) if \(n\epsilon^2\to\infty\).

  3. Size of the set.

    \[\bigl(1-\delta_T(\epsilon,n,\P)\bigr)\, 2^{n(1-\epsilon)H(\P)} \le |\Tcal_\epsilon^{(n)}(\P)| \le 2^{n(1+\epsilon)H(\P)}.\]
Proof.

  1. Apply the lemma to \(g := \log\P\): we have \(\frac{1}{n}\log\P^n(x^n) = \frac{1}{n}\sum_{i=1}^n \log\P(x_i)\) and \(\EE_\P\bigl[|\log\P(\rv{X})|\bigr] = H(\P)\). Next, \(\log\frac{\hat{\P}_{x^n}(a)}{\P(a)} \le \log(1+\epsilon)\) whenever \(\hat{\P}_{x^n}(a) > 0\), and averaging under \(\hat{\P}_{x^n}\) bounds the divergence. Finally, \(H(\hat{\P}_{x^n}) = H(\hat{\P}_{x^n}\|\P) - D(\hat{\P}_{x^n}\|\P)\), and the lemma with \(g = \log\P\) also gives \(|H(\hat{\P}_{x^n}\|\P) - H(\P)| \le \epsilon H(\P)\).

    We write the bounds on \(\P^n(x^n)\) as \(\P^n(x^n)\approx 2^{-nH(\P)}\). Sequences satisfying them are called weakly typical, so strong typicality implies weak typicality. The converse fails: if \(\P\) is uniform and \(M\ge 2\), every \(x^n\) is weakly typical, including \(x^n = a_1 a_1\cdots a_1\), which is not strongly typical for \(\epsilon < 1\).

  2. For each \(a\in\Xcal\), the random variables \(\ind{\rv{X}_1 = a},\ldots,\ind{\rv{X}_n = a}\) are i.i.d., with values in \([0,1]\) and mean \(\P(a)\), and their arithmetic mean is \(\hat{\P}_{\rv{X}^n}(a)\). If \(\P(a) = 0\), then \(\hat{\P}_{\rv{X}^n}(a) = 0\) with probability \(1\). By the union bound and Hoeffding’s inequality (the mean of \(n\) independent random variables with values in \([0,1]\) deviates from its expectation by more than \(t\) with probability at most \(2e^{-2nt^2}\)),

    \[\begin{aligned} \P^n\bigl(\rv{X}^n\notin\Tcal_\epsilon^{(n)}(\P)\bigr) &\le \sum_{a:\,\P(a)>0} \P^n\Bigl(\Bigl|\frac{1}{n}\sum_{i=1}^n \ind{\rv{X}_i = a} - \P(a)\Bigr| > \epsilon\P(a)\Bigr) \\ &\le \sum_{a:\,\P(a)>0} 2e^{-2n\epsilon^2\P(a)^2} \le 2M^* e^{-2n\epsilon^2 c_\P}. \end{aligned}\]
  3. By item 1, \(|\Tcal_\epsilon^{(n)}(\P)|\, 2^{-n(1+\epsilon)H(\P)} \le \P^n\bigl(\Tcal_\epsilon^{(n)}(\P)\bigr) \le |\Tcal_\epsilon^{(n)}(\P)|\, 2^{-n(1-\epsilon)H(\P)}\). Use \(\P^n\bigl(\Tcal_\epsilon^{(n)}(\P)\bigr) \le 1\) on the left and \(\P^n\bigl(\Tcal_\epsilon^{(n)}(\P)\bigr) \ge 1-\delta_T(\epsilon,n,\P)\) (item 2) on the right.

So the probability of an i.i.d. source \(\P^n\) concentrates on \(\Tcal_\epsilon^{(n)}(\P)\), a set of about \(2^{nH(\P)}\) sequences out of all \(M^n = 2^{n\log M}\), and every sequence in it has probability about \(2^{-nH(\P)}\). This is the asymptotic equipartition property (AEP).

Comparison with type classes.

The properties above parallel those of a type class (Section 2.2.3), with probabilities under \(\hat{\P}^n\) for the type class \(\Tcal^{(n)}(\hat{\P})\) and under \(\P^n\) for the typical set \(\Tcal_\epsilon^{(n)}(\P)\):

type class \(\Tcal^{(n)}(\hat{\P})\)typical set \(\Tcal_\epsilon^{(n)}(\P)\)
probability of a sequence\(2^{-nH(\hat{\P})}\)\(2^{-n(1\pm\epsilon)H(\P)}\)
size of the set\(\gamma_n(\hat{\P})\, 2^{nH(\hat{\P})}\)\(2^{n(1\pm\epsilon)H(\P)}\)
probability of the set\(\gamma_n(\hat{\P})\to 0\) polynomially\(\ge 1-\delta_T(\epsilon,n,\P)\to 1\)

where the exponents \((1\pm\epsilon)H(\P)\) stand for the bounds of items 1 and 3. A single type class has a vanishing probability, but only polynomially fast: \(\gamma_n(\hat{\P}) \ge K_{n,M}^{-1} \ge (n+1)^{-(M-1)}\), so the loss is invisible on the exponential scale. In contrast, \(\Tcal_\epsilon^{(n)}(\P)\), a union of the type classes close to \(\P\), carries almost all the probability; the price is the slack \(\pm\epsilon\) in the exponents.

Conversely, type classes give a tighter lower bound on the size, without any concentration argument. For every type \(\hat{\P}\in\Pcal_n\) with \(|\hat{\P}(a)-\P(a)| \le \epsilon\P(a)\) for all \(a\),

\[|\Tcal_\epsilon^{(n)}(\P)| \ge |\Tcal^{(n)}(\hat{\P})| = \gamma_n(\hat{\P})\, 2^{nH(\hat{\P})} \ge K_{n,M}^{-1}\, 2^{nH(\hat{\P})}.\]

Such a type exists for \(n\) large enough. Rounding each \(n\P(a)\) up or down gives \(\hat{\P}\in\Pcal_n\) with \(|\hat{\P}(a)-\P(a)| < \frac{1}{n}\) for all \(a\), and \(\hat{\P}(a) = 0\) if \(\P(a) = 0\). With \(\P_{\min} := \min_{a:\,\P(a)>0}\P(a)\) and \(\tau_n := \frac{1}{n\P_{\min}}\), we get \(|\hat{\P}(a)-\P(a)| \le \tau_n\P(a)\) for all \(a\), so item 1, applied with \(\tau_n\) to any \(x^n\in\Tcal^{(n)}(\hat{\P})\), gives

\[H(\hat{\P}) \ge (1-\tau_n)H(\P) - \log(1+\tau_n) \ge H(\P) - \frac{H(\P)+\log e}{n\P_{\min}},\]

since \(\log(1+\tau_n) \le \tau_n\log e\). Hence, for \(n \ge \frac{1}{\epsilon\P_{\min}}\) (so that \(\tau_n \le \epsilon\)),

\[|\Tcal_\epsilon^{(n)}(\P)| \ge K_{n,M}^{-1}\, 2^{nH(\P) - \frac{H(\P)+\log e}{\P_{\min}}},\]

that is, \(\frac{1}{n}\log|\Tcal_\epsilon^{(n)}(\P)| \ge H(\P) - O\bigl(\frac{\log n}{n}\bigr)\), much better than \((1-\epsilon)H(\P)\).

2.4 Jointly and conditionally typical sequences

Let \(\P_{\rv{X}\rv{Y}}\in\Pcal(\Xcal\times\Ycal)\) be a joint distribution with marginals \(\P_{\rv{X}}\) and \(\P_{\rv{Y}}\). In the same way, the jointly typical set is

\[\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}) := \Bigl\{(x^n,y^n) :\ \bigl|\hat{\P}_{x^n,y^n}(a,b) - \P_{\rv{X}\rv{Y}}(a,b)\bigr| \le \epsilon\,\P_{\rv{X}\rv{Y}}(a,b),\ \forall\,(a,b)\in\Xcal\times\Ycal\Bigr\},\]

and, for \(y^n\in\Ycal^n\), the conditionally typical set is

\[\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n) := \bigl\{x^n :\ (x^n,y^n)\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}})\bigr\}.\]

By definition,

\[(x^n,y^n)\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}) \iff x^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n) \iff y^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond x^n).\]

Below, \(\P^n(x^n)\approx 2^{-n(1\pm\epsilon)H}\) means \(2^{-n(1+\epsilon)H} \le \P^n(x^n) \le 2^{-n(1-\epsilon)H}\), and \(\delta_T\) is defined in Section 2.3.

Properties.

  1. If \((x^n,y^n)\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}})\), then \(x^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}})\), \(y^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{Y}})\),

    \[\begin{gathered} \P_{\rv{X}}^n(x^n)\approx 2^{-n(1\pm\epsilon)H(\rv{X})},\quad \P_{\rv{Y}}^n(y^n)\approx 2^{-n(1\pm\epsilon)H(\rv{Y})}, \\ \P_{\rv{X}\rv{Y}}^n(x^n,y^n)\approx 2^{-n(1\pm\epsilon)H(\rv{X},\rv{Y})}, \\ \P_{\rv{Y}|\rv{X}}^n(y^n\cond x^n)\approx 2^{-n(1\pm\epsilon)H(\rv{Y}\cond\rv{X})},\quad \P_{\rv{X}|\rv{Y}}^n(x^n\cond y^n)\approx 2^{-n(1\pm\epsilon)H(\rv{X}\cond\rv{Y})}. \end{gathered}\]
  2. \(\bigl(1-\delta_T(\epsilon,n,\P_{\rv{X}\rv{Y}})\bigr)\, 2^{n(1-\epsilon)H(\rv{X},\rv{Y})} \le |\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}})| \le 2^{n(1+\epsilon)H(\rv{X},\rv{Y})}\).
  3. For every \(y^n\in\Ycal^n\), \(|\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)| \le 2^{n(1+\epsilon)H(\rv{X}\cond\rv{Y})}\).

  4. Conditional typicality lemma. Let \(\P_{\rv{X}^n|\rv{Y}^n} = \P_{\rv{X}|\rv{Y}}^n\). For every \(y^n\in\Tcal_{\epsilon/2}^{(n)}(\P_{\rv{Y}})\),

    \[\P_{\rv{X}^n|\rv{Y}^n=y^n}\bigl(\rv{X}^n\notin\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\bigr) \le \delta_T(\epsilon/2,n,\P_{\rv{X}\rv{Y}}),\]

    which tends to \(0\) if \(n\epsilon^2\to\infty\).

  5. For every \(y^n\in\Tcal_{\epsilon/2}^{(n)}(\P_{\rv{Y}})\),

    \[|\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)| \ge \bigl(1-\delta_T(\epsilon/2,n,\P_{\rv{X}\rv{Y}})\bigr)\, 2^{n(1-\epsilon)H(\rv{X}\cond\rv{Y})}.\]

  6. Joint typicality lemma. For every \(y^n\in\Ycal^n\),

    \[\P_{\rv{X}}^n\bigl(\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\bigr) \le 2^{-n(I(\rv{X};\rv{Y}) - 2\epsilon H(\rv{X}))},\]

    and for every \(y^n\in\Tcal_{\epsilon/2}^{(n)}(\P_{\rv{Y}})\),

    \[\P_{\rv{X}}^n\bigl(\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\bigr) \ge \bigl(1-\delta_T(\epsilon/2,n,\P_{\rv{X}\rv{Y}})\bigr)\, 2^{-n(I(\rv{X};\rv{Y}) + 2\epsilon H(\rv{X}))}.\]

    So an \(\rv{X}^n\sim\P_{\rv{X}}^n\) drawn independently of \(y^n\) is jointly typical with \(y^n\) with probability about \(2^{-nI(\rv{X};\rv{Y})}\).

Proof.
  1. Summing over \(b\), \(\hat{\P}_{x^n}(a) = \sum_b \hat{\P}_{x^n,y^n}(a,b)\) is within \(\epsilon\P_{\rv{X}}(a)\) of \(\P_{\rv{X}}(a)\), and similarly for \(y^n\). The bounds follow from the typical average lemma for \(\P_{\rv{X}\rv{Y}}\) with \(g(a,b) = \log\P_{\rv{X}}(a)\), \(\log\P_{\rv{Y}}(b)\), \(\log\P_{\rv{X}\rv{Y}}(a,b)\), \(\log\P_{\rv{Y}|\rv{X}}(b\cond a)\) and \(\log\P_{\rv{X}|\rv{Y}}(a\cond b)\). For example, \(\log\P_{\rv{X}|\rv{Y}}^n(x^n\cond y^n) = \sum_{i=1}^n \log\P_{\rv{X}|\rv{Y}}(x_i\cond y_i)\) and \(\EE\bigl[|\log\P_{\rv{X}|\rv{Y}}(\rv{X}\cond\rv{Y})|\bigr] = H(\rv{X}\cond\rv{Y})\).
  2. This is property 3 of Section 2.3 applied to \(\P_{\rv{X}\rv{Y}}\).

  3. By item 1,

    \[1 \ge \sum_{x^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)} \P_{\rv{X}|\rv{Y}}^n(x^n\cond y^n) \ge |\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)|\, 2^{-n(1+\epsilon)H(\rv{X}\cond\rv{Y})}.\]
  4. Given \(\rv{Y}^n = y^n\), the \(\rv{X}_i\) are independent with \(\rv{X}_i\sim\P_{\rv{X}|\rv{Y}=y_i}\). If \(\P_{\rv{X}\rv{Y}}(a,b) = 0\), then \(\hat{\P}_{\rv{X}^n,y^n}(a,b) = 0\) with probability \(1\). Otherwise, \(\hat{\P}_{\rv{X}^n,y^n}(a,b)\) is the mean of the \(n\) independent random variables \(\ind{(\rv{X}_i,y_i) = (a,b)}\), with values in \([0,1]\), and its expectation is \(\hat{\P}_{y^n}(b)\P_{\rv{X}|\rv{Y}}(a\cond b)\). Since \(y^n\in\Tcal_{\epsilon/2}^{(n)}(\P_{\rv{Y}})\), this expectation is within \(\frac{\epsilon}{2}\P_{\rv{X}\rv{Y}}(a,b)\) of \(\P_{\rv{X}\rv{Y}}(a,b)\). A deviation from \(\P_{\rv{X}\rv{Y}}(a,b)\) by more than \(\epsilon\P_{\rv{X}\rv{Y}}(a,b)\) therefore needs a deviation from the expectation by more than \(\frac{\epsilon}{2}\P_{\rv{X}\rv{Y}}(a,b)\), which has probability at most \(2e^{-n\epsilon^2\P_{\rv{X}\rv{Y}}(a,b)^2/2}\) by Hoeffding’s inequality. The union bound over the pairs with \(\P_{\rv{X}\rv{Y}}(a,b) > 0\) gives \(\delta_T(\epsilon/2,n,\P_{\rv{X}\rv{Y}})\). (With \(y^n\) only in \(\Tcal_\epsilon^{(n)}(\P_{\rv{Y}})\), the expectation can lie on the boundary, and the probability need not tend to \(1\).)

  5. By item 4 and item 1,

    \[\begin{aligned} 1-\delta_T(\epsilon/2,n,\P_{\rv{X}\rv{Y}}) &\le \P_{\rv{X}^n|\rv{Y}^n=y^n}\bigl(\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\bigr) \\ &\le |\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)|\, 2^{-n(1-\epsilon)H(\rv{X}\cond\rv{Y})}. \end{aligned}\]

  6. Every \(x^n\in\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\) is in \(\Tcal_\epsilon^{(n)}(\P_{\rv{X}})\), so \(\P_{\rv{X}}^n(x^n)\approx 2^{-n(1\pm\epsilon)H(\rv{X})}\). With item 3,

    \[\P_{\rv{X}}^n\bigl(\Tcal_\epsilon^{(n)}(\P_{\rv{X}\rv{Y}}\cond y^n)\bigr) \le 2^{n(1+\epsilon)H(\rv{X}\cond\rv{Y})}\, 2^{-n(1-\epsilon)H(\rv{X})} \le 2^{-n(I(\rv{X};\rv{Y}) - 2\epsilon H(\rv{X}))},\]

    since \(H(\rv{X}\cond\rv{Y}) \le H(\rv{X})\). The lower bound follows in the same way from item 5.

  1. Problem 1 Types and type classes by hand

    • Compute \(\Q^3\bigl(\Tcal^{(3)}(\hat{\P})\bigr)\) for every \(\hat{\P}\in\Pcal_3\), and check that the probabilities add up to \(1\). Which sequence is the most likely under \(\Q^3\)? Which type classes are the most likely?

  2. Problem 2 Number of types CK 2.1

    Let \(M = |\Xcal|\).

    • Show that \(K_{n,M} = |\Pcal_n| = \binom{n+M-1}{M-1}\). Hint: a type is given by the counts \((n_1,\ldots,n_M)\). Write \(n\) stars on a line and put \(M-1\) bars among them to split the stars into \(M\) groups; for instance, \(\star\star|\,|\star\) stands for \((2,0,1)\).

      \[|\Tcal^{(n)}(\hat{\P})| = \frac{n!}{\prod_{i=1}^M n_i!} = \binom{n}{n_1,\ldots,n_M}.\]

    • Deduce the multinomial identity \(\sum \binom{n}{n_1,\ldots,n_M} = M^n\), where the sum is over \((n_1,\ldots,n_M)\in\mathbb{Z}_+^M\) with \(\sum_i n_i = n\).
