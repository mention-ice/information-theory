# Elements of Information Theory

Course website: https://mention-ice.github.io/information-theory/

Notes, quizzes and problems of the course *Elements of Information Theory* (Sheng Yang,
CentraleSupélec, 2026–2027). The page of each lecture goes online after the lecture.

The site in `docs/` is generated from the LaTeX sources of the course; do not edit it by hand.

Every page loads the anonymous visit counter of the course telemetry server
(`<script defer src="https://bit2noisy-telemetry.sheng-yang-e9e.workers.dev/v.js" data-site="it"></script>`
after `assets/site.js`, and the footer line "Visits are counted anonymously, without cookies.").
The generator must add both when it rebuilds the site.
